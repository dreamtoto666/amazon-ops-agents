# Feature Specification: 竞品画像数据获取

**Feature Branch**: `002-competitor-profile-data`  
**Created**: 2026-09-17  
**Status**: In progress  
**Input**: 用户要求将竞品对比的数据处理画像调整为四个数据获取模块，并以 JSON 分模块传递给报告 Agent。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 获取流量词与变体流量分布 (Priority: P1)

运营人员提交自有父 ASIN 和竞品父 ASIN 后，可以查询两个 Listing 及其变体的流量词和流量分布，用于理解不同变体的自然与广告流量构成。

**Why this priority**: 流量词、Listing 流量分布和变体差异是竞品画像的基础数据。

**Independent Test**: 提供两个父 ASIN 和各自变体的样例数据，验证输出 JSON 中保留 Listing 自然/广告流量分布、广告流量分布，以及每个返回变体的对应数据。

**Acceptance Scenarios**:

1. **Given** 可查询的父 ASIN，**When** 请求查流量词，**Then** 输出包含该 Listing 的自然流量与广告流量分布、广告流量分布，以及返回变体的数据。
2. **Given** 调用方提交两个父 ASIN，**When** 请求竞品对比，**Then** 系统仅以这两个父 ASIN 查询，并从返回结果保留变体范围。

---

### User Story 2 - 对比单个流量词与多变体自然位 (Priority: P1)

运营人员可在同一份画像中查看自有 ASIN 和竞品 ASIN 的高贡献流量词，并区分流量词的总流量、自然流量和广告流量占比，以及多自然位带来的额外自然流量。

**Why this priority**: 这是识别关键词流量机会和变体布局差异所需的核心对比数据。

**Independent Test**: 提供含有 1% 边界值、上升期数据和多自然位数据的自有/竞品样例，验证仅按规定门槛返回关键词，且字段完整地分模块传给报告 Agent。

**Acceptance Scenarios**:

1. **Given** 自有 ASIN 的单个流量词总流量占比大于 1%，**When** 请求反查流量词，**Then** 输出该词的总流量、自然流量、广告流量占比，以及与上升期相比的流量变化。
2. **Given** 竞品 ASIN 的单个流量词总流量占比大于 1%，**When** 请求反查流量词，**Then** 输出该词的总流量、自然流量和广告流量占比。
3. **Given** 自有或竞品 ASIN 的关键词给 Listing 贡献的自然流量占比大于 1%，**When** 请求查多变体自然位，**Then** 输出该关键词的自然流量及占比，以及因多自然位额外获得的自然流量。

---

### User Story 3 - 对比推荐专栏周期数据 (Priority: P2)

运营人员可获得自有 ASIN 当前周期、过去周期中流量得分最高的三个周期，以及竞品 ASIN 当前周期的推荐专栏数据，以比较推荐入口的流量和广告活动情况。

**Why this priority**: 推荐专栏是补充流量结构的对比维度，应与关键词和变体数据一并进入报告。

**Independent Test**: 提供包含多个周期、多个推荐专栏且含 1% 边界值的样例，验证输出只包含规定周期和流量占比大于 1% 的推荐专栏，并保留专栏名称、流量占比和广告活动数量。

**Acceptance Scenarios**:

1. **Given** 自有 ASIN 有当前周期和过去周期数据，**When** 请求查推荐专栏，**Then** 输出当前周期及过去周期中流量得分最高的三个周期的推荐专栏数据。
2. **Given** 竞品 ASIN 有当前周期数据，**When** 请求查推荐专栏，**Then** 输出该当前周期的推荐专栏数据。
3. **Given** 推荐专栏流量占比等于或低于 1%，**When** 整理推荐专栏数据，**Then** 不将该专栏写入输出；流量占比大于 1% 时保留专栏名称、流量占比和广告活动数量。

### Edge Cases

- 父 ASIN 不存在、不可访问或没有返回数据时，模块须如实表达数据不可得，不能用其他 ASIN 或推测值代替。
- 任一模块的数据源未返回所需字段或周期时，须在该模块 JSON 中标明缺失字段或缺失周期；不得编造、补零或把缺失数据解释为业务结论。
- 流量占比恰好为 1% 的关键词或推荐专栏不应进入要求为“>1%”的数据集合。
- 某 ASIN 没有多自然位额外流量时，须按数据源实际返回表达，不能推断额外流量。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统必须将竞品对比的数据处理画像拆分为四个独立 JSON 模块：`traffic_keyword_lookup`（查流量词）、`traffic_keyword_reverse_lookup`（反查流量词）、`multi_variant_organic_position`（查多变体自然位）和 `recommendation_placement`（查推荐专栏）。
- **FR-002**: `traffic_keyword_lookup` 必须仅接受自有父 ASIN 和竞品父 ASIN 查询；必须传递 Listing 的自然流量和广告流量分布、广告流量分布及父 ASIN 查询实际返回的不同变体数据。
- **FR-003**: 查流量词的不同变体数据必须原样包含数据源实际返回的总流量占比、自然—广告流量分布、自然流量占比、SP（常规）流量占比、SP（推荐）流量占比、SB（常规）流量占比和 SBV 流量占比；如某字段未返回，必须如实标为缺失。
- **FR-004**: `traffic_keyword_reverse_lookup` 必须为自有 ASIN 传递单个流量词中总流量占比大于 1% 的数据；每个词必须传递总流量、自然流量、广告流量占比，以及相对于上升期的流量变化。
- **FR-005**: `traffic_keyword_reverse_lookup` 必须为每个竞品 ASIN 传递单个流量词中总流量占比大于 1% 的数据；每个词必须传递总流量、自然流量和广告流量占比。
- **FR-006**: `multi_variant_organic_position` 必须为自有 ASIN 和每个竞品 ASIN 传递给 Listing 贡献的自然流量占比大于 1% 的关键词；每个词必须传递给 Listing 贡献的自然流量及占比，以及因多自然位额外获得的自然流量。
- **FR-007**: `recommendation_placement` 必须为自有 ASIN 传递当前周期和过去周期中流量得分最高的三个周期的数据，并为每个竞品 ASIN 传递当前周期的数据。
- **FR-008**: `recommendation_placement` 中只传递流量占比大于 1% 的推荐专栏；每条数据必须包含推荐专栏名称、流量占比和广告活动数量。
- **FR-009**: 系统必须以模块化 JSON 将四类数据传递给报告 Agent；每条记录保留其所属模块、目标 ASIN、周期（适用时）及数据来源可提供的原始证据关联信息。
- **FR-010**: 系统不得在本规格明确的“流量占比 >1%”、指定周期或数据可得性之外擅自增加、放宽或更改任何过滤条件。
- **FR-011**: 系统不得为缺失的占比、流量变化、多自然位额外流量、推荐专栏或广告活动数量编造数值、默认值或结论。
- **FR-012**: 报告 Agent 接收到的 JSON 必须能区分自有父 ASIN、竞品父 ASIN、各返回变体 ASIN，以及每个模块的完整或缺失状态。

### Key Entities

- **竞品画像数据包**: 一次竞品对比中传递给报告 Agent 的 JSON 根对象，由四个固定数据模块组成。
- **流量词记录**: 一个 ASIN 的单个关键词流量记录，包含适用的总流量、自然流量、广告流量占比和自有 ASIN 的上升期变化。
- **变体流量记录**: Listing 中一个变体 ASIN 的流量分布数据，包含自然与广告分布及广告类型占比。
- **多变体自然位记录**: 一个关键词为 Listing 带来的自然流量、占比与多自然位额外自然流量。
- **推荐专栏记录**: 指定 ASIN 与周期的推荐专栏名称、流量占比和广告活动数量。
- **数据缺失说明**: 某模块、字段、ASIN 或周期未被数据源返回时的如实状态和原因。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 对含有四类完整样例数据的竞品对比请求，报告 Agent 在一次接收中获得全部 4 个命名 JSON 模块，且每个模块均可识别所属 ASIN 与适用周期。
- **SC-002**: 在包含占比为 0.99%、1.00% 和 1.01% 的验收样例中，所有要求“>1%”的集合只保留 1.01% 的记录，准确率为 100%。
- **SC-003**: 在包含父 ASIN、子 ASIN 和至少两个变体的验收样例中，查流量词模块能保留每个返回变体的全部规定流量分布字段或其真实缺失状态，字段覆盖率为 100%。
- **SC-004**: 在包含当前周期、多个过去周期和多个竞品的验收样例中，推荐专栏模块为自有 ASIN提供当前周期和过去周期中流量得分最高的 3 个周期，为每个竞品提供当前周期，且没有额外周期。
- **SC-005**: 在任何缺失字段、缺失周期或不可访问 ASIN 的验收样例中，传给报告 Agent 的 JSON 不包含编造数值；缺失项均可从对应模块状态中识别。

## Assumptions

- “反差流量词”按上下文理解为“反查流量词”。
- “上升期”使用数据源为自有 ASIN 明确提供或标记的上升期；系统不自行推断上升期，也不以未说明的周期替代。
- “过去周期中三个流量得分最高的周期”不包含当前周期；当前周期作为单独要求传递。
- 请求只传入 1 个自有父 ASIN 和 1 个竞品父 ASIN；Sif 在父 ASIN 查询结果中返回变体数据，调用方不传子 ASIN。
- 本功能只定义数据获取、规定过滤和 JSON 交接，不定义报告 Agent 对数据的解释、排序或经营建议。
- 附图用于说明变体流量数据应覆盖的展示字段，不构成额外的筛选、计算或阈值要求。
