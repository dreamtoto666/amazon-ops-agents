# 欧洲报关表填写自动化

该功能不使用 LLM、数据库或上传文件中的其他工作表。用户上传一个 `.xlsx`，系统只读取 `Sheet1`，按渠道、目的地前缀和国家将数据拆分为固定 24 类：华贸卡航/华贸海运/华贸空运/一八海运 × 红福/其它 × 德国/法国/英国。

- 渠道分别归一为华贸卡航、华贸海运、华贸空运或一八海运；目的地以“红福”开头时归为红福，否则归为其它。
- 红福对应 `9810`，其它对应 `0110`；没有商品的分类不会生成文件。
- 报关单运输方式按分类渠道填写：华贸卡航为“公路运输”、华贸海运和一八海运为“水路运输”、华贸空运为“航空运输”。
- 同一分类的商品按内置报关商品规则和上传的报关单价汇总；分类总净重固定为总毛重的 92%，再按上传重量比例分摊并补齐尾差；金额为数量×报关单价。
- 输出沿用既有六联报关单模板：红福使用 `9810` 模板，其它使用 `0110` 模板。最终目的国自动填写德国、法国或英国；0110 会更新运抵国和指运港，9810 还会更新贸易国。原产国、境内货源地和征免等固定字段继续保留模板填写规则。出口日期自动使用上海当天，运费保持模板原值。
- API：`POST /api/european-customs-declarations/preview` 与 `/generate`，均使用 `file` multipart 字段。生成成功时返回 ZIP。
