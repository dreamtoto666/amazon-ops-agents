# 01. 范围与目标

## 目标

为目标项目提供对话式 ChatBI：用户可连续提问，系统可分流、查询授权数据、受限计算、生成图表并返回结果。

## 本期范围

1. 对话 API 与多轮会话。
2. 普通咨询、纯计算、业务数据分析三类意图。
3. Schema 读取、自然语言查数和只读 SQL。
4. 基于工具结果的多步 ReAct 数据分析。
5. Python 计算与图表。
6. 多 MCP 服务编排。

## 不在本期范围

- 评论分析、相关性分析、销量预测。
- Excel 自动导入数据库。
- 任意数据库写操作、结构变更和跨租户查询。
- 无限制 Python、网络访问和系统命令。

## 成功标准

- 授权用户完成查数和作图闭环。
- SQL 与代码执行安全边界可验证。
- 不依赖课程源码中的固定 IP、绝对路径或密钥。
