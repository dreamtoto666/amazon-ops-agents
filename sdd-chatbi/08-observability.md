# 08. 可观测性与降级

## 审计事件

记录请求 ID、用户/租户、会话、意图、工具名称、耗时、状态、SQL 指纹、结果行数、沙箱资源使用和图表结果。不得记录敏感数据或密钥。

## 降级

| 故障 | 返回策略 |
|---|---|
| Schema 服务失败 | 说明数据目录不可用 |
| SQL 失败 | 返回安全查询失败，可有限重试 |
| 图表失败 | 返回已验证的文本结果 |
| 模型超时 | 返回请求 ID 与重试提示 |
| 工具轮数超限 | 返回当前结论和限制 |

## 指标

端到端耗时、成功率、工具错误率、SQL 拒绝率、沙箱超时率、图表成功率和每会话工具调用数。
