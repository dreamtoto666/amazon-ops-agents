# 12. 关键设计决策

## ADR-001：使用 LangGraph

LangGraph 管理状态、固定路由和 ReAct 子图；适合同时存在确定流程与多步工具决策的 ChatBI。

## ADR-002：按能力拆分 MCP

分流、数据库、Python 分别部署，获得独立扩缩容、最小权限和故障隔离；代价是增加服务间认证和观测要求。

## ADR-003：数据库严格只读

ChatBI 不拥有写库或 DDL 权限，写操作必须使用目标项目既有后台流程。

## ADR-004：Python 必须隔离

不采用课程源码直接执行模型代码的方式；模型代码视为不可信输入。

## ADR-005：应用持久化会话

会话使用目标项目数据库或会话服务，而非仅进程内 MemorySaver，以支持多实例、权限隔离和数据保留。
