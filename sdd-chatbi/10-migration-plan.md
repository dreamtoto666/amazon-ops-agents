# 10. 移植计划

## 阶段 0：盘点

确认目标项目框架、认证、数据库、ORM、前端、对象存储、部署、模型供应商与日志规范。

## 阶段 1：基础对话

建立模块、配置、会话存储、模型客户端和普通对话 API。

## 阶段 2：安全查库

确定业务表白名单和注释；实现 Database MCP、SQL 防护、审计和 Schema 到 SQL 链路。

## 阶段 3：智能编排

实现 Router MCP、LangGraph 主图、ReAct 子图和轮数限制。

## 阶段 4：计算与图表

实现隔离沙箱、Python MCP、图表存储与前端展示。

## 阶段 5：上线

完成安全、性能和真实业务问题评估，灰度发布并配置监控。
