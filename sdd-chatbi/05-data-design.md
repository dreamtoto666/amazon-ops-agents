# 05. 数据与会话设计

## 业务数据

ChatBI 仅可查询明确白名单中的表或视图。每张表必须有稳定英文表名、字段名、中文业务注释、单位说明、数据更新时间和必要的租户字段。

## Schema 元数据

Schema 工具返回表名、字段、类型、中文注释和必要样例值。不得返回敏感列、系统表、密钥或未授权数据源。

## 会话记录

| 字段 | 说明 |
|---|---|
| id | 消息 ID |
| session_id | 会话 ID |
| user_id / tenant_id | 权限边界 |
| role | user 或 assistant |
| content | 最终文本 |
| created_at | 时间 |

工具审计、SQL 指纹、错误和耗时写入受控审计记录，而非普通聊天记录。
